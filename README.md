# Vibes

Vibe packs for coding agents. Browse at [vibing.supply](https://vibing.supply).

## Structure

Each vibe lives in `skills/vibe/vibes/<name>/` with:
- `vibe.json` — configuration data
- `SKILL.md` — skill file for `/vibe <name>`

## Contributing

1. Fork this repo
2. Create `skills/vibe/vibes/<your-vibe>/`
3. Add `vibe.json` (see `schema/vibe.schema.json` for format)
4. Add `SKILL.md` (copy from an existing vibe as template)
5. Submit PR
